# Pong — Phosphor Court

A glowing CRT-style duel against a computer paddle, first to seven points.

## Features

- Mouse, touch and keyboard paddle control
- Three CPU difficulties with different reactions and accuracy
- A ball that accelerates with every paddle hit
- First-to-seven win overlay with a rematch button
- Current rally and all-time longest rally tracking
- Pause at any time with P or Space
- Best rally and difficulty saved locally

- A How to play popup with the controls and scoring rules.

## Running it

Open `index.html` in a browser. There is no build step and no dependencies to install.
